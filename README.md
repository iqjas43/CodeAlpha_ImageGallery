# Interactive Image Gallery - CodeAlpha

An interactive and responsive image gallery web application built as part of my Frontend Development Internship at CodeAlpha.

## 🚀 Features
* **Real-Time Search**: Instantly filter images by typing titles or keywords.
* **Category Filters**: Easily switch between categories like Nature, Architecture, Technology, and Games.
* **Lightbox Modal View**: Click on any image to open a full-screen modal preview with a download option.
* **Responsive Design**: Fully optimized layout that adapts seamlessly across all devices.

## 🛠️ Tech Stack
* **HTML5**: Structured semantic layout.
* **CSS3**: Modern dark-mode styling, flexbox/grid, and transitions.
* **JavaScript**: Dynamic DOM manipulation, event handling, and search/filter logic.
